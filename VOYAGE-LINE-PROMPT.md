# Golden Voyage Overlay

## Prompt

Create a single continuous antique-gold voyage thread for a monumental, elegant mythological editorial website. Transparent RGBA background, tall 1:3 composition. The thread enters near the upper center, sweeps boldly across almost the entire width, doubles back through generous asymmetric bends, and descends through three broad, irregular S-shaped passages before exiting near the lower center. Let it feel carried by a sea current: fluid, slightly unpredictable, unhurried, never mechanically symmetrical. The sweeping gesture should be extravagant; the line itself should remain exquisitely thin. A sharply defined metallic gold core with changing champagne highlights, subtle bronze undertones, delicate tapering, and a narrow soft halo. Preserve large areas of completely empty transparent space for marble sculptures and typography. Magnificent scale, restrained craftsmanship, the luminous trace of a long sea journey. One uninterrupted thread only, no branching or disconnected strokes.

## Exclude

No background, ocean image, parchment, fog layer, statues, people, lettering, logos, arrows, compass symbols, stars, particles, glowing orbs, frames, symmetrical ellipses, geometric orbit diagrams, thick ribbons, neon orange, laser beams, blown-out bloom, or baked-in checkerboard.

## Integration

The existing website keeps its live SVG voyage line. Use this prompt for a decorative raster alternative, not a replacement for the responsive path geometry. Verify that the generated file actually contains transparency before compositing it. Keep the overlay below readable text, and end it above the concluding sentence of the three statue stories; retain the sea below that point.
