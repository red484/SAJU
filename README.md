# SAJU · 제0관측소

사주와 신화의 서사를 바다 항로, 조각상 포스터, 다섯 장의 기록으로 표현한 정적 웹 프로토타입입니다.

## 실행

`index.html`은 첫 방문에 온보딩을, 온보딩 완료 후 재방문에는 메인 홈을 엽니다. `home.html`은 메인 홈을 직접 여는 주소입니다. `onboarding.html`은 온보딩, `result.html`은 결과 화면입니다. 별도 빌드나 패키지 설치는 필요하지 않습니다. Google Fonts 로딩에는 인터넷 연결이 필요합니다.

홈은 조각상 표지와 세 가지 미리보기(오늘의 안내·기록·서재)로 구성합니다. 세로 하강 그림과 네 조각 항해 장면은 홈의 시각적 미리보기로 배치하고 각 기능 페이지로 연결합니다. 실제 기능은 다음 페이지에 분리되어 있습니다.

- `calendar.html`: 관심사 선택, 오늘의 메시지와 작은 실천, 이번 주 추천 날짜, 월간 달력과 날짜별 안내
- `readings.html`: 경계·방향·골조의 본문, 이어 읽기, 상세·구매 미리보기와 책갈피
- `library.html`: 나의 신화 다시 읽기, 책갈피한 물음 열기와 삭제

페이지를 이동해도 같은 기기의 책갈피와 관심사를 이어서 사용합니다. 기존 `home.html?question=...`와 홈 내부 달력·기록·서재 링크는 새 페이지로 연결됩니다. 결과 화면의 질문은 기록 상세로, 메인 홈 버튼은 홈 미리보기로 이동합니다. 온보딩은 변경하지 않았습니다.

9,900원은 예시 가격이며 실제 결제·주문은 만들지 않습니다. 달력 안내는 관심사와 요일에 따른 편집 예시이며 실제 사주 계산이나 포스텔러 데이터 연동이 아닙니다. 같은 세션에 남아 있는 온보딩의 회복 방식과 부족한 것에 대한 답변만 참고합니다. 생년월일을 새로 저장하지 않고 관심사·책갈피·오늘의 실천 선택만 현재 기기에 보관합니다.

## 주요 파일

- `index.html`, `entry.js`, `journey.js`: 첫 방문 및 재방문 분기
- `home.html`, `home-preview.js`: 홈 미리보기와 기존 링크 호환
- `calendar.html`, `readings.html`, `library.html`: 분리된 기능 페이지
- `readings.js`: 기록 상세, 분류, 책갈피와 서재
- `pages.css`: 공통 페이지 메뉴와 홈 미리보기 스타일
- `calendar-model.js`, `calendar.js`, `calendar.css`: 관심사 기반 달력 모델, 날짜 선택 및 맞춤 기록
- `onboarding.html`: 입력 및 영상 온보딩
- `result.html`, `result.js`: 결과 화면과 인터랙션
- `result.css`, `reading.css`, `poster.css`, `epic.css`: 화면 스타일
- `assets/`: 이미지, 영상, 항로 선, 아이콘
- `RESULT-GENERATION-PROMPT.md`: 결과 JSON 생성 프롬프트와 구조
- `epic.sample.json`: 샘플 신화 서사
- `validate-result.mjs`: 샘플 데이터 검증
- `ART-DIRECTION.md`, `EPIC-UPDATE.md`, `VOYAGE-LINE-PROMPT.md`: 디자인 및 작업 문서

현재 결과는 샘플 서사입니다. 실제 사주 계산 및 결과 생성 API는 연결되어 있지 않습니다.

## 검증

Node.js가 설치된 환경에서 실행합니다.

```sh
node validate-result.mjs
node validate-calendar.mjs
node validate-pages.mjs
node --check result.js
```

## 홈 디자인 업데이트

재방문 홈, 오늘의 물음, 세 가지 심층 기록 상세, 책갈피 보관, 모바일 하단 내비게이션을 제공합니다. 결과 마지막의 질문은 각 심층 기록 상세로 바로 연결됩니다. 계정·실제 결제·사주 분석은 연동되지 않았습니다.

Sites 정적 게시용 파일은 `node build.mjs`로 생성합니다.

홈 2차 디자인: 검정·금색 편집 지면, 판화 표지, 경계·방향·골조의 짧은 글과 이어 읽기. 글은 디자인을 위한 창작 예시이며 개인 사주 해석이 아닙니다.

첫 방문 흐름은 `/` → `onboarding.html` → `result.html` → `home.html`입니다. 온보딩에서 결과로 이동할 때 완료 여부만 현재 기기에 저장합니다. 같은 기기의 재방문은 홈으로 이동하며, 저장이 차단된 환경에서도 결과의 홈 버튼은 홈을 직접 엽니다. 기존 `index.html?question=...` 링크는 유지됩니다.

## 스크롤 장면

홈의 기록 미리보기에서 하강 지면은 화면 너비를 채우는 긴 세로 그림과 그 아래 여백의 타이틀로 구성됩니다. 그림은 일반 스크롤로 읽으며 고정·낙하 애니메이션이 없습니다. 홈의 서재 미리보기에서 네 조각이 합쳐지는 항해 장면만 스크롤 위치에 맞춰 움직이며 스크롤 입력은 가로채지 않습니다. 작은 화면·큰 글씨·동작 줄이기 설정에서는 고정 장면을 풀어 일반 문서로 표시합니다. 각 장면에 건너뛰기 링크가 있습니다. `node validate-scroll.mjs`로 동작 분기와 스크롤 갱신을 검증합니다.
